# Trabalho1

Esse repositório foi criado apenas para poder desenvolver um trabalho de Algoritmos e estruturas de dados em conjunto com o meu grupo.
O trabalho consiste em criar um programa em C para fazer algumas operações simples com vetores. Para rodar, recomendo que utilize o software Dev-C++ e crie um projeto com os arquivos que foram publicados aqui.

**COMO RODAR:**
1. Faça o download dos arquivos e os deixe numa página separada;
2. Abra o arquivo Trabalho1.dev no Dev-C++;
3. Compile e execute (F11) o arquivo Trabalho1.c;
4. Pronto! você já está rodando o programa!
